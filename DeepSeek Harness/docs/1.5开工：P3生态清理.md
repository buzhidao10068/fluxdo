## 三、关联行为与兼容处理

### 个人页与帖子菜单

- 移除个人页余额卡的启用标记读取、首次激活状态、重新授权回调，以及手动刷新中的余额请求。
- 全局用户状态刷新和退出登录不再创建已移除的余额 provider。
- 删除“多元宇宙”“信任要求”导航入口；私信、聊天、徽章、邀请和其他标准论坛入口保留。
- 帖子菜单不再读取打赏凭证或显示 LDC 操作。回复、分享、书签、采纳等标准功能保留。

### 旧统计配置迁移

旧 `profile_stats_config` 可能含 `dataSource: connect` 或 Connect 专属项。直接删除枚举、把未知项目逐个替换为 `daysVisited` 会造成重复项目或错误布局，因此本轮做了显式兼容：

1. 数据源统一为 `summary`。
2. 保留有效 Summary 项目的原顺序，去除重复项目。
3. 删除 `topicsRepliedTo`、`likesReceivedDays`、`likesReceivedUsers` 及其它未知项目。
4. 原列表非空但全部失效时恢复默认四项；用户主动保存的空列表仍为空。
5. 保留有效布局和列数；非法列数回退为 4，避免网格循环或布局异常。
6. provider 读取旧配置后写回规范化结果，防止每次启动重复读取旧数据源。
7. 配置保存定时器在 provider 销毁时取消，避免延迟回调访问已销毁的 ref。

编辑页不再显示只有一个选项的数据源切换；统计预览、卡片都只读取 `userSummaryProvider`。错误提示改为实际的加载失败信息，不再声称“已回退到全量统计”。

### Cookie 与备份

- critical Cookie 集合只剩 `_t`、`_forum_session`、`cf_clearance`。
- 不扩大发送论坛登录 Cookie 的范围；主域 host-only 策略和子域隔离回归继续通过。
- 删除旧站 `auth.session-token` 专属日志分支，包括原先输出原始 Set-Cookie 的诊断；通用 Cookie 能力保留。
- 备份导出和导入过滤 `ldc_` / `cdk_` 前缀，覆盖旧开关、缓存及历史明文凭证；恢复旧备份不会重新注入这些旧功能设置。
- 代码中残留的 `ldc_` / `cdk_` 过滤字符串是兼容旧备份的规则，不是可执行生态入口。设备上的历史数据未做无差别删除；删除服务后不会再读取或使用旧打赏凭证。

### 四语言本地化

- 删除 reward、metaverse 生态语言包和散落在 auth/user/post/navToast/common 中的废弃条目。
- 旧 metaverse 包实际混放了 `chat_thread`、`github_commentedOn`、`github_moreFiles`、`github_viewFullCode`。它们属于通用正文渲染，已分别迁至 chat 和新建 github 模块，四语言全部保留。
- 执行 `dart tool/gen_l10n.dart`，重新生成 slang 和兼容层；生成文件遵循仓库既有规则不入 Git。
- 原有未提交的品牌替换保持保留，本轮只处理被删除功能相关的文案。
