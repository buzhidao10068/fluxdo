### ⚠ 证据缺口（重要，未复核）

文档第 5 节声称实测 `hcaptcha_site_key = d2a8ddf6-4c2a-4054-ac7c-2e288c2477aa`，但本轮匿名复核：

- `about.json` 的 `site` 键为空（匿名不下发）
- `site.json` 全树扫描无 `captcha/hcaptcha` 任何键
- `/login` 页面 HTML 无 captcha 标记，且无 `csrf-token` meta、无 preloaded 节点（服务端返回反爬壳）

因此该 sitekey **无法在脚本环境证伪/证实**。当前实现两者兼容：站点要验证码 → 写入该 key 即走原流程；不要 → 留空跳过。**建议开工时第一件事是按待办风险 2 真机登录抓一次 cookie 与登录响应**。
